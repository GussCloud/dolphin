The Dolphin CLI is the `dolphin` command-line interface for scripting a running Dolphin editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control Dolphin-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → Dolphin CLI](/docs/settings). On Linux the command is `dolphin-ide`, because KDE's Dolphin file manager already owns `/usr/bin/dolphin` — see [Install → Linux](/docs/install#linux).

Agents can install the matching Dolphin CLI skill with:

```bash
npx skills add https://github.com/GussCloud/dolphin --skill dolphin-cli
# headless / no Settings UI:
dolphin skills install --skill dolphin-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable Dolphin skill, including `dolphin skills install` / `dolphin skills update`.

## Install & verify

```
command -v dolphin
dolphin status --json
```

## Worktree commands

```
dolphin worktree ps --json
dolphin worktree create --repo id:<repoId> --name my-task --issue 123 --json
dolphin worktree current --json
dolphin worktree set --worktree active --comment "reproduced bug" --json
dolphin worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [Dolphin CLI reference](/docs/cli/reference).

## Terminal commands

```
dolphin terminal list --json
dolphin terminal read --json
dolphin terminal send --text "continue" --enter --json
dolphin terminal wait --for tui-idle --timeout-ms 30000 --json
dolphin terminal create --worktree path:/projects/app --command "npm test" --json
dolphin terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs in the active Dolphin worktree from a shell:

```
dolphin file open src/App.tsx
dolphin file diff src/App.tsx --staged
dolphin file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `dolphin tab profile`; start with `dolphin tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `dolphin automations` to create, inspect, run, and remove scheduled Dolphin tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in Dolphin account (`dolphin artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
dolphin goto --url https://example.com --json
dolphin snapshot --json     # returns refs like @e1, @e3
dolphin click --element @e3 --json
dolphin fill --element @e1 --value "user@example.com" --json
dolphin screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
dolphin set device --name "iPhone 12" --json
dolphin screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through Dolphin's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator from `dolphin emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving Dolphin.

```
dolphin emulator list --json
dolphin emulator attach "<device-name-or-udid>" --json
dolphin emulator tap 0.5 0.7 --json
dolphin emulator type "hello" --json
dolphin emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
dolphin emulator rotate landscape_left --json
dolphin emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
