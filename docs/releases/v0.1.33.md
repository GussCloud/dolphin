# Dolphin v0.1.33

## Improvements

- **The default Agent Teams instructions now tell Claude exactly how to start teammates.** Before, Claude could start a helper inside the lead's own session instead of a real teammate pane. The new text also avoids characters that PowerShell 5.1 or `cmd` mangle on the launch command line.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
