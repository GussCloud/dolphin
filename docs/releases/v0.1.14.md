# Dolphin v0.1.14

## Fixes

- **Very large Markdown previews no longer freeze the window.** Previews over the size limit ask before rendering ("Render anyway"), and documents past the hard cap are not rendered.
- **Windows: when the system is out of memory, Dolphin asks before reloading a crashed window** instead of reloading into the same crash again.
- **Terminals that show inline images (Sixel) no longer run out of memory with many tabs open.** An image that cannot be decoded is dropped instead of leaving the terminal stuck.
- **Scrolling over a full-screen terminal app while its pane is being moved no longer types `;NaN;NaNM` into the app.**
- **Hidden terminal tabs now have a memory cap.** The oldest hidden tabs are parked once the budget is exceeded, and restored when you open them.
- **Terminals recover on their own after the background terminal service crash-loops**, instead of staying stuck until Dolphin is reopened.
- **Agent status updates no longer pause the window while they are saved.**
- **Windows: files ending in `.asar` inside a workspace can be deleted and replaced while Dolphin is open.**
- **A terminal whose height lands exactly on a row boundary no longer flickers one line up and down.**

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
