# Dolphin v0.2.46

## macOS

- **Dolphin for macOS is now signed and notarized by Apple, so it updates itself.** It opens without the "unidentified developer" warning, and new versions download and install from inside the app, as on Windows.

**One manual step if you already use Dolphin on a Mac:** v0.2.45 and earlier cannot install this version by themselves. Download `dolphin-macos-arm64.dmg` (Apple silicon) or `dolphin-macos-x64.dmg` (Intel) from this release and drag Dolphin to Applications once. macOS may ask again for the permissions you had granted (folders, camera, Accessibility). Every later version updates automatically.

Windows: update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
