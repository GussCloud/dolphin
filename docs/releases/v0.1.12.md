# Dolphin v0.1.12

## Behavior change

- **An unexpected error in Dolphin's main process now closes the app instead of freezing it.**
  - Before, the error opened a native error box, sometimes hidden behind other windows, and Dolphin stopped responding until it was force-quit.
  - Now the error is recorded and Dolphin exits. Your terminal sessions keep running in the background and reattach when you reopen Dolphin.

## Fixes

- **Closing the tab of an untitled note no longer deletes it after it was saved.** Only an empty, never-saved placeholder is removed.
- **Fixed a crash ("Object has been destroyed") when the main window closed while it was changing focus.**
- **Antivirus software can no longer take down the whole app package.** The SSH relay is now shipped once, outside `app.asar`, so a false positive on it does not remove `app.asar` too.
- **Windows (WSL): a timed-out WSL command no longer leaves orphaned processes behind.** The whole process tree is stopped, not only `wsl.exe`.
- **Linux (AppImage): quitting no longer produces a false crash report** from the crash handler outliving the AppImage mount.
- **Linux (containers): Dolphin no longer crash-loops when `/dev/shm` is small.** Set `DOLPHIN_DEV_SHM=off` or `force` to override the detection.
- **Linux: `dolphin open --disable-gpu` passes the flag to the app**, for GPUs that crash Chromium (for example Intel i915).
- **Mobile: native chat keeps fewer off-screen rows in memory**, so long conversations scroll more smoothly.
- **Leftover temporary files from interrupted mobile settings writes are cleaned up at startup.**

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
