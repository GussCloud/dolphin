# Dolphin v0.1.1

## Fixes

- **`dolphin diagnostics runtime` on Windows no longer reports a false "Untracked under daemon".**
  - Every Windows terminal runs as two daemon children: the shell and its `OpenConsole.exe` ConPTY host. The host was counted as unexplained.
  - It is now paired with its shell, so it no longer counts.
  - A console host with no live shell is still reported, because that one would be a real leak.
- **The main window, tray notice, and push notifications say "Dolphin" instead of "Dolphin".**
  - Windows Task Manager showed the main process as "Dolphin" because it lists the window title.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
