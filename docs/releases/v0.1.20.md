# Dolphin v0.1.20

## New

- **Brazilian Portuguese (pt-BR) interface.** It is picked automatically on pt-BR systems; European Portuguese still falls back to English.
- **Team instructions for Claude Agent Teams.** Settings > Agents has a "Team instructions" field, sent to Claude on every launch (local, WSL, SSH and resume), so Claude uses a team even when you type the first message straight into the terminal. It ships with a default text; leave it empty to turn it off. A system prompt flag you pass yourself still wins.

## Fixes

- **A quoted Claude instruction containing `&` or `>` no longer silently turns off Agent Teams** for that launch.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
