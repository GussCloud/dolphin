# Dolphin v0.1.15

Ships with Dolphin Mobile 0.0.59.

## Fixes

- **Mobile: a screen that crashes no longer closes the whole app.** A recovery screen offers Retry, Return home and Report error, and the next launch mentions the previous crash so its details can be shared.
- **Mobile: Live input no longer carries text from one terminal into another.** Switching to a terminal in another workspace starts with an empty field, even when both terminals share a name.
- **Mobile: opening a new tab no longer waits on "Detecting agents" every time.** Agents already detected on the current connection show right away and are refreshed in the background.

Update the phone app from its store or the latest Android release.
