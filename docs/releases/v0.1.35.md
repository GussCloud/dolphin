# Dolphin v0.1.35

## Improvements

- **Creating a worktree no longer spends seconds working out your Git user name for the branch name.** The name is remembered per repository and refreshed in the background.
- **The base branch update no longer competes with the new worktree's checkout**, which made creation slower.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
