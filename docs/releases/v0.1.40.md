# Dolphin v0.1.40

## Improvements

- **More hidden terminals are released from memory:**
  - Hibernated agent tabs are released once hidden, and wake up when you open them.
  - The closed floating terminal panel is released after it stays closed for 5 minutes.
  - Hidden terminals that must stay loaded now count toward the hidden-tab memory budget, so the others are released sooner when it is exceeded.

## Fixes

- **The memory chip in the status bar refreshes every 10 seconds** instead of looking frozen until clicked.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
