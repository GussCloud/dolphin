# Dolphin v0.1.41

## Fixes

- **Deleting the workspace you are looking at no longer shows "Terminal exited" or opens a new terminal elsewhere.**
  - A successful delete is silent; a delete that does not finish shows its own message.
  - Dolphin then moves only to a workspace that is already awake, and never starts a terminal there.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
