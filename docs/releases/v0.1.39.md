# Dolphin v0.1.39

## New

- **The Resource Manager chip in the status bar warns when memory runs over budget.** A warning triangle appears, and the tooltip lists each owner (the Dolphin window, the terminal service or a session) with its usage and limit.
- **`dolphin diagnostics runtime` shows heap use** for the app and the terminal service. Older hosts simply leave this section out.

## Improvements

- **Dolphin gives back memory when the computer runs low.**
  - Hidden terminals and their graphics memory are released, and come back when you open them.
  - Idle agents are hibernated sooner (down to one minute when memory is critical), heaviest first, even while the window is hidden.
- **Windows: the Resource Manager no longer starts PowerShell on every refresh.** Memory and CPU are read directly from the system.
- **Lower memory use in the background:**
  - Terminals with no visible pane (background agents, mobile or remote only) keep 2,000 rows instead of 5,000.
  - Closed terminals stop holding their last output once the process has exited.
  - Claude and Codex usage tracking stores much shorter keys and skips rewriting its cache when nothing changed.
  - The background terminal service has a memory ceiling (2 GB, or a quarter of RAM on small machines), so a runaway leak restarts it instead of slowing the whole computer. Set `DOLPHIN_DAEMON_MAX_OLD_SPACE_MB` to change it, or `0` to turn it off.

## Fixes

- **SSH: Git replies can no longer pile up in memory on the remote host.** At most 16 run at once, and one whose reader stops responding fails after 60 seconds.
- **Going back to an older Dolphin rebuilds the usage cache** instead of misreading the newer format.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
