# Dolphin v0.1.13

## Fixes

- **Fewer freezes while Dolphin checks your repositories.** Git lookups that used to pause the whole window (default branch, worktree lists) now run in the background, and a change in one repository only re-lists that repository instead of all of them.
- **Opening Dolphin in a repository with hundreds of old worktrees no longer hangs.** The active workspace and anything with a live terminal load right away; idle and completed worktrees load when you open them. `dolphin status` reports `unresponsive` instead of `starting` when the app is running but not answering.
- **Windows: dismissing a mobile notification no longer briefly freezes the app.** The file permission update runs in the background.
- **Updating Dolphin no longer leaves the previous background terminal service running without a way to stop it.** An older service whose access token an update deleted is now shut down.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
