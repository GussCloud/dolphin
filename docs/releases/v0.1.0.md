# Dolphin v0.1.0

Dolphin is the first release of this fork of [Orca](https://github.com/stablyai/orca), built from upstream Orca 1.4.214. It focuses on keeping many agents running for days without leaking processes, terminals, memory, or disk.

**Windows only.** The installer is **unsigned**, so SmartScreen will warn on first run: choose *More info → Run anyway*. Dolphin installs beside the official Orca. It uses its own install folder, data folder (`%APPDATA%\dolphin`), terminal daemon, and update feed (this repository). The two apps never share state and never update each other.

## What's new over upstream

- **`orca diagnostics runtime`** reports where memory goes (main, renderer, terminal daemon, session trees), how many processes each session holds, and disk used by terminal history, Codex homes, and logs. It also lists every mismatch between saved tabs, the daemon's live sessions, and tracked terminals, such as orphaned daemon sessions and saved tabs that will reopen empty. It only reports; nothing is killed. (#1, #6)
- **Explicit session lifecycle**: terminal sessions move through `running → stopping → terminated → reaped`, with timestamps. The daemon reports sessions that are mid-kill as `exiting`, and `daemon.log` gains stop and reap events. (#2)
- **Orphan reaper**: child processes that survive a terminal kill are logged, re-checked after 10 s, and killed again, but only after confirming the process identity, so a reused PID is never touched. This runs on macOS and Linux. On Windows the job object already owns the process tree. (#3)
- **Memory budget warnings**: diagnostics flag a renderer over 1500 MB, a daemon over 512 MB, or a session over 1024 MB. Limits are configurable through `ORCA_WARN_*_MEMORY_MB`. (#4)
- **`orca gc`** reclaims terminal history that was previously never deleted. It skips live sessions, sessions a saved tab can still restore, sessions under crash recovery, and anything active in the last day. It removes nothing if a daemon does not answer. Use `--dry-run` to preview. (#5)
- **Long-running benchmark**: `config/scripts/session-lifecycle-benchmark.mjs` has `churn` and `soak` modes, with pass/fail verdicts. (#7)

## CLI

Inside Dolphin's terminals, `orca` reaches Dolphin, as it does in Orca. From an outside shell, use `dolphin`, since the official Orca may own `orca` on your PATH.

See `docs/reference/fork-identity.md` for exactly what is separated from upstream Orca.
