# Dolphin v0.1.19

## Improvements

- **Windows: Claude Agent Teams teammates start in about 6.5 seconds instead of 17–23.**
  - Teammate panes talk to Dolphin over a dedicated, token-protected channel instead of starting a command-line call for each step.
  - A new split pane no longer waits about 4 seconds for a window that is not shown yet.
  - Teammate Git Bash panes receive their start script directly instead of having it typed in.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
