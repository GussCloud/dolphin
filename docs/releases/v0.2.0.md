# Dolphin v0.2.0

## New

- **Agents office in the organization console.** A live view shows every organization member whose Dolphin is running, the projects they have open and what each agent is doing (working, waiting for permission, or idle). It is view-only. Owners can create display links to show it on a TV without signing in, and revoke them.
- **Dolphin shares agent activity with your organization's console** while you are signed in and belong to a Dolphin organization.
  - Only the repository name, branch, agent type, its state, your computer's name and anonymous IDs are sent: never prompts, messages, file paths or titles.
  - Your presence is removed when you quit or sign out.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
