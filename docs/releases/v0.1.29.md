# Dolphin v0.1.29

## New

- **OpenObserve integration.** Settings > Integrations has a new Observability section with an OpenObserve card.
  - Dolphin detects `openobserve-cli`, saves the server, organization and sign-in method, and runs `auth login` in a terminal, so secrets stay in the CLI's own keychain storage.
  - It also installs the CLI's companion agent skill and lists safe example commands.
  - Status is checked on the host the workspace runs on, local or remote.

Update from inside Dolphin, or reinstall with `dolphin-windows-setup.exe`.
